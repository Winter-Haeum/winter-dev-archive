## 🔬 체계적 분석 방법론

<div class="wda-callout wda-ci">
  <span class="wda-clabel">레퍼런스 분석 방법</span>
  레퍼런스 사이트를 보며 감상만 하지 말고, 체계적으로 분석해보세요. 다음 Claude 프롬프트를 사용하여 구체적인 인사이트를 얻을 수 있습니다.
</div>

<div class="wda-prompt-head">💬 Claude에 보낼 분석 프롬프트</div>

```
다음 포트폴리오 사이트를 분석해줘: [사이트 URL]

1. 첫인상 분석
- 3초 안에 어떤 인상을 받는가?
- 방문자가 가장 먼저 주목하게 되는 요소는?
- 전체적인 분위기와 브랜드 톤앤매너는?

2. 디자인 요소 분석
- 색상 팔레트와 그 효과
- 타이포그래피 선택과 가독성
- 레이아웃과 여백 활용 방식
- 시각적 계층구조 (Visual Hierarchy)

3. 사용자 경험 (UX) 분석
- 네비게이션의 직관성
- 정보 구조의 논리성
- 인터랙션과 애니메이션의 적절성
- 모바일 반응형 대응 수준

4. 콘텐츠 전략 분석
- 자기소개 방식과 개성 표현
- 프로젝트 소개의 구성과 깊이
- 연락처 및 CTA의 접근성
- 전체적인 스토리텔링 구조

5. 장점과 개선점
- 이 포트폴리오의 가장 큰 강점 3가지
- 아쉬운 점이나 개선 가능한 부분
- 내 포트폴리오에 적용할 만한 아이디어
- 차별화할 수 있는 방향성

6. 타겟 분석
- 어떤 직무/회사를 목표로 하는 것 같은가?
- 어떤 경력 수준의 지원자로 보이는가?
- 이 접근 방식이 효과적일 것 같은 이유
```

```
레퍼런스 분석을 바탕으로 내 포트폴리오 아이디어를 구체화해줘:

1. 나의 포지셔닝
- 목표 직무: [예: 프론트엔드 개발자, 웹디자이너, 풀스택 개발자]
- 경력 수준: [예: 신입, 1년차, 경력직]
- 지원 회사 성격: [예: 스타트업, 대기업, 에이전시]
- 나만의 강점: [예: 디자인 감각, 기술적 깊이, 소통 능력]

2. Hero 섹션 컨셉
레퍼런스에서 인상적이었던 Hero 섹션: [사이트명]
내가 적용하고 싶은 요소:
- 헤드라인 스타일: [예: 임팩트형, 스토리텔링형, 기술중심형]
- 시각적 요소: [예: 미니멀, 일러스트, 3D, 애니메이션]
- 색상 톤: [예: 모노톤, 파스텔, 비비드, 다크]
- 차별화 포인트: [내만의 독특한 아이디어]

3. About Me 섹션 구성
참고한 About 섹션: [사이트명]
내 이야기 구성:
- 개발 시작 스토리: [간략한 계기와 여정]
- 핵심 가치관: [개발할 때 중요하게 생각하는 것]
- 개인적 매력: [취미, 관심사, 개성]
- 성장 목표: [앞으로의 발전 방향]

4. Skill 섹션 차별화
인상적이었던 스킬 표현: [사이트명]
내 스킬 구성:
- 주력 기술 (5개): [예: HTML, CSS, JavaScript, React, Node.js]
- 표현 방식: [예: 프로그레스 바, 원형 차트, 카드형, 인터랙티브]
- 숙련도 기준: [정확한 평가 기준]
- 추가 표시 정보: [예: 경험 년수, 프로젝트 수, 인증]

5. 전체 디자인 방향
- 전체 컬러 팔레트: [메인 3-4색]
- 폰트 스타일: [예: 모던, 클래식, 개성있는]
- 레이아웃 스타일: [예: 미니멀, 매거진형, 카드형]
- 애니메이션 수준: [예: 미니멀, 적당함, 화려함]

6. 차별화 전략
- 경쟁자 대비 내 강점: [구체적인 차별점]
- 타겟 어필 포인트: [채용 담당자가 매력을 느낄 요소]
- 독창적 아이디어: [아무도 하지 않은 나만의 접근법]

위 내용을 바탕으로 구체적인 포트폴리오 기획서를 작성해줘.
```
